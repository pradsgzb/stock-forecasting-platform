# ADR-0001: Record Architecture Decisions

- Status: Accepted
- Date: 2026-11-03

## Context

The platform will accumulate choices whose rationale can otherwise be lost or repeatedly
re-litigated.

## Decision

Record strategic decisions as immutable Markdown ADRs. Superseding an ADR creates a new ADR
that links to the old one; history is not rewritten.

## Consequences

Reviewers can trace why technologies and boundaries were selected. Documentation maintenance
becomes part of the definition of done.
